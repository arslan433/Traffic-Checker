 Website Traffic Checker (Next.js + SimilarWeb API)

A modern web app built with Next.js that allows users to check website traffic insights using the SimilarWeb API.  
It displays metrics such as total visits, engagement rate, traffic sources, and top countries — all in a clean, responsive UI.

---

 Live Demo
> https://artrafficchecker.vercel.app/

---

Features
Search any domain to view its analytics  
Shows total visits, pages per visit, avg. visit duration & bounce rate  
Displays traffic sources (direct, referral, search, social, etc.)  
Top countries & similar sites data  
Built with Next.js (Server Components / API routes)  
Uses the official SimilarWeb API  
Dark mode supported (if added)
